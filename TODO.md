- Memory-destination ops (add/sub/cmp/... on a stack slot) need their operand size from the destination type, not the immediate, or narrower locals get clobbered
- Typed extern declarations (e.g. `extern def strcmp(a: *char, b: *char): i32;`) so calls sign/zero-extend narrow return values; untyped externs read all of rax, but Win64 leaves the upper 32 bits of an int return undefined (works on MSVC CRT, breaks under Wine)
- Make calls to undeclared externs a type error instead of typing them as `Unknown`, with a prelude declaring `printf`, `malloc`, `exit`, etc. (replaces the hardcoded `exit` in `Program::compile`)
- Variadic externs via trailing `...` (e.g. `extern def printf(fmt: *char, ...): i32;`): arg count check becomes `given >= fixed`, extra args still type checked and structs rejected, `f32` promoted to `f64`, `al` set to the vector register count on SysV

  - Dead code elimination

  - reuse registers for intermediate results instead of allocating new ones

- recursive generic struct should require generic type on same type field
- Generic instance names are built from the function name and concrete types only, so two different shadowing generics called with the same types (e.g. two `g<T>` templates both called with `u8`) share one cached `g__u8` instance and clash at codegen
- Evaluate a `for` range's end bound once instead of every iteration: it's desugared into the loop condition, so `for i in 0..f()` calls `f` on every pass
- `Type::Unknown` is both "unchecked" and a wildcard; give unchecked expressions their own state (e.g. `etype: Option<Type>`)
- `Named` equals `Struct`/`Enum` by name, so two different structs with the same name compare equal; self-referential fields have to stay `Named`, so this needs a unique id per struct definition
- Generic struct instances keep the template's name, so lookups by name conflate `List<u8>` and `List<i64>`
- `Declaration` wraps `Assignment`, allowing an `op` and non-variable `lhs` the parser never produces; store name, annotation and value directly

- Split tokens into identifiers, literals, `Keyword` and `Punct` (`;` `:` `,` are atoms and keywords are identifiers, so `Parser::expect` compares strings)
- Split `types.rs` (`Token`, int types, `Span`) into the stages that own them
- Move calling-convention constants (volatile/non-volatile/arg registers, `passed_by_pointer`) out of `compile_call.rs` into one module
- Add `reserve_stack`/`free_stack` on `Codegen` instead of `compile_call.rs` editing `stack_depth` directly
- Split the generics machinery out of `TypeScope`, which is really the whole type checker's context
